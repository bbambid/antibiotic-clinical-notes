# 抗菌薬の使い分けノート

個人学習用PWA。薬剤各論・疾患別ノート・臨床メモを扱います。

## プライバシー
アプリ本体と初期の医学解説はGitHub Pages上で公開されます。ユーザーが入力するメモと添付画像はブラウザ内のIndexedDBに保存され、GitHubに送信されません。Safariのサイトデータ削除や端末変更で消える可能性があるため、定期的にバックアップをエクスポートしてください。患者個人情報は登録しないでください。

## 利用
GitHub Pagesでmainブランチのルートを配信し、iPhone Safariで開いて「ホーム画面に追加」。医学解説は学習用の初稿であり、最新の添付文書・ガイドラインとの個別照合が必要です。
